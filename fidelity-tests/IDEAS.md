# Ideas for fixtures and tasks

Untested angles. Take from here when writing a prompt or a task list; strike through what
has been built.

## Fixture mess (combine several per paragraph)
- Emoji and non-Latin text in headings, list items, table cells
- Numbered list that becomes a checklist halfway; nested bullets inside a table cell
- Text pasted from Word / Slack / Notion with fonts and sizes attached
- Bold 14pt Normal text imitating a heading, next to a real heading
- A phrase repeated three times with different formatting, once inside a link
- Empty paragraphs carrying formatting; trailing spaces; tabs for alignment; manual "1)"
- Chip or link inside a table cell; comment anchored across a formatting boundary
- Suggestions left pending; a resolved comment on text that has since changed
- Same phrase differing only by case, curly vs straight quotes, en dash vs hyphen

## Task angles
- Edit a word inside a link, a bold run, a heading's first word, a list item, a table
  cell, a footnote, a header, under a comment anchor, inside a pending suggestion
- Rewrite a whole section; insert a paragraph between two list items
- Change a value that lives in a chip (date, dropdown); tick a checklist item
- Reply to, resolve, or reopen a comment; accept or reject a suggestion
- A request whose target phrase also appears elsewhere
- Something the API almost certainly cannot do (resize a drawing, add a suggestion)

## Suite-level
- Two agents editing the same doc at once (conflict detection)
- Fixtures copied from real internal docs (work account, never committed)
